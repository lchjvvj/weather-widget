## 🌤️ 天气桌面小工具 — 多城市同屏天气桌面插件

> 一款支持多城市同屏显示、可自定义的桌面天气小工具，专为 Deepin/UOS 桌面环境设计。
> 基于 Python + Tkinter 构建，2071 行代码，6 个模块化组件。

### ✨ 功能特性

| 特性 | 说明 |
|------|------|
| 🏙️ **多城市同屏** | 同时展示多个城市的实时天气，支持搜索/添加/删除/排序 |
| 📅 **3天预报** | 每个城市展示未来3天天气趋势（温度、天气描述） |
| 🔍 **城市搜索** | 支持拼音/汉字实时搜索过滤，129个常用城市一键添加 |
| 📦 **数据缓存** | 10分钟缓存 + 断网自动显示旧数据 + 提示用户 |
| 🔄 **自动重试** | 网络请求失败自动指数退避重试，确保数据可靠性 |
| 🌙 **深色主题** | 现代化深色 UI，护眼舒适，与 Deepin 完美融合 |
| 🎨 **自定义背景** | 支持本地图片作为背景，自动压暗+模糊处理 |
| 🖱️ **拖拽移动** | 自由拖动窗口，位置自动保存记忆 |
| ⌨️ **快捷键** | F5 刷新、Esc 最小化 |
| 💾 **配置持久化** | 城市列表、背景图片、窗口位置全部自动保存 |

### 🏗️ 技术架构

| 技术 | 用途 |
|------|------|
| Python 3.8+ / Tkinter | GUI 桌面界面 |
| wttr.in API | 免费天气数据源（无需 API Key） |
| 多线程并发 | 同时获取多城市天气数据 |
| Pillow | 背景图片缩放、亮度调节、模糊处理 |
| 指数退避重试 | 网络请求失败自动重试 |
| JSON 配置 | 城市列表、背景路径、窗口位置持久化 |

**架构模式：MVC 三层架构**
- 数据层（Model）：weather_api.py — 数据获取、缓存、重试
- 视图层（View）：weather_ui.py — 窗口渲染、卡片布局
- 控制层（Controller）：settings_dialog.py + config_manager.py — 城市管理、配置持久化

### 💬 开发过程说明（基于 deepin Skills）

本作品全程通过 **UOS AI（小U同学）** 辅助开发，核心使用了以下 deepin Skills：

1. **data-analysis** — 天气数据处理、图表渲染逻辑
2. **dtk-development** — 桌面应用架构设计指导

**开发历程：**
1. **需求分析**：与 AI 讨论多城市天气插件的功能需求，确定技术栈（Python + Tkinter）
2. **架构设计**：AI 建议采用 MVC 模块化架构，分离数据层、视图层、控制层
3. **核心开发**：
   - AI 编写天气数据获取模块（weather_api.py），含多线程并发、缓存、重试机制
   - AI 编写 UI 渲染模块（weather_ui.py），含圆角卡片、图文混排、悬停效果
   - AI 编写城市管理对话框（settings_dialog.py），含搜索过滤、排序功能
4. **问题修复**：AI 协助修复了城市名校验误报、窗口位置记忆、断网保护等 bug
5. **优化迭代**：AI 协助优化了代码结构、添加注释、完善文档
6. **作品包装**：AI 协助生成作品集文档、README、安装脚本
